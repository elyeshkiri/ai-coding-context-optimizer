# `token-saver snippet`

Extract one exact symbol body from a source file.

## Synopsis

```bash
token-saver snippet <file> <symbol> [-q|--quiet]
```

## Arguments and options

- `file` and `symbol` required.
- `-q/--quiet` suppresses auxiliary note.

## Exit codes

`0` success; nonzero when file/symbol extraction fails.

## Output contract

Exact source snippet.

## Authoritative runtime help

Run `token-saver snippet --help` for argparse's exact usage text for the installed version.
