# `token-saver status`

Read Token Saver's on-disk session ledger.

## Synopsis

```bash
token-saver status [path]
```

## Arguments and options

- `path` default `.`.

## Exit codes

`0` success.

## Output contract

Human state summary.

Run `token-saver status --help` for argparse's exact usage text for the installed version.
